# مصلّح برو | Reparateur Pro

تطبيق Android أولي لتسيير محل إصلاح الهواتف، مصمم للعمل دون اتصال بالإنترنت.

## بناء APK
كل تغيير على الفرع `main` يشغّل GitHub Actions. من تبويب Actions افتح آخر عملية ناجحة ثم نزّل artifact باسم `Reparateur-Pro-debug-apk`.

## تنبيه
هذه نسخة أولية تجريبية تحتاج إلى اختبار فعلي قبل البيع. ملف debug APK ليس إصدارًا نهائيًا موقّعًا. وظائف الطباعة Bluetooth تحتاج إلى تنفيذ واختبار منفصلين.
